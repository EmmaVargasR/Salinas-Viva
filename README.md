# Salinas Viva: Red Vial y Microempresas

Maqueta interactiva 3D del territorio de Salinas de Guaranda para el museo
de la parroquia. Proyecto de la materia Programación Avanzada (Yachay Tech).

## Tecnologías
- Unity 6000.0.xx (LTS) con URP
- C# (aplicación) y C++ (plugin nativo y firmware)

## Cómo abrir el proyecto
1. Instalar **la misma versión de Unity** indicada arriba.
2. Instalar Git y Git LFS.
3. Clonar el repo y abrir la carpeta desde Unity Hub (Add project from disk).
